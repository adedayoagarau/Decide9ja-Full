# Commit Changes

Review and commit the current changes with a descriptive commit message.

1. Run `git status` to see all changed files
2. Run `git diff` to review the changes
3. Stage relevant files (not .env or secrets)
4. Write a clear commit message following conventional commits format:
   - `feat:` for new features
   - `fix:` for bug fixes
   - `refactor:` for code refactoring
   - `docs:` for documentation
   - `chore:` for maintenance
5. Create the commit
6. Show the commit result
