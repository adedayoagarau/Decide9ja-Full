# Nigerian 2023 Presidential Election Data

## Contents

### 1. Official Election Results
*   **File:** `presidential_2023_official.json`
*   **Description:** Official INEC results for the 2023 Presidential Election broken down by state plus FCT.
*   **Candidates:** Bola Tinubu (APC), Atiku Abubakar (PDP), Peter Obi (LP), Rabiu Kwankwaso (NNPP).
*   **Format:** JSON (State, Candidate Votes).

### 2. EDA Notebook
*   **File:** `eda-presidential-nigeria-election-2023.ipynb`
*   **Source:** Kaggle Kernel by nimahmasuud
*   **Description:** Exploratory Data Analysis notebook focusing on 2023 election tweets.
*   **Note:** The underlying tweet dataset (`nigerian_presidential_election_2023_tweets.csv`) could not be downloaded directly due to API limitations, but insights were extracted into `data/social/twitter_2023_analysis.json`.

## Analysis Findings
*   **Winner:** Bola Tinubu (APC)
*   **Twitter Sentiment:** Mixed, with high engagement for Peter Obi (LP) and extensive discourse around `#NigeriaDecides2023`.
